Privacy Policy & Terms of Use

Last updated: November 26, 2026

1. Data Collection, Cookie-Free Referrer Analytics & Static Hosting

khoaphan.dev is statically hosted on GitHub Pages. We do not sell personal data, store third-party advertising cookies, or log IP addresses or sensitive credentials. Local UI preferences (theme, motion, and language) stay in your browser's localStorage, first-touch inquiry attribution (?ref= / HTTP referrer) stays in ephemeral sessionStorage, and aggregate cookie-free pageview/referrer counts are measured via Counter.dev without cross-site tracking.

2. First-Party Social & Developer API Integrations

Official integrations with LinkedIn API and X API v2 are used strictly for first-party publishing of technical articles authored on khoaphan.dev by Khoa Phan (@KPhan407 / in/khoa-phan-55bab8448). OAuth tokens are never shared with third parties and can be revoked at any time.

3. Contact

For privacy or security inquiries, contact khoa@khoaphan.dev.
