# khoaphan.dev — Khoa Phan Personal Brand & Verified Proof-of-Work Hub

Official website and personal brand hub for **Khoa Phan (Phan Đăng Khoa)** — Polyglot Systems, Web3 & Custom MCP Architect (`Rust` • `Go` • `TypeScript` • `Python`).

## Routes
- `/` — Flagship Portfolio, Click-to-Verify Upstream Proof Matrix, 6 MIT Toolkits, Products (`vrm3d.com`, `uploadhtml.com`), Engagement Tracks & Project Brief Builder
- `/links/` — Self-Hosted All-Platform Link-in-Bio Hub
- `/brand/` — Official Brand Guidelines, Vector SVG Logos, Color Tokens, Multi-Platform Social Banners & Standardized Bios
- `/arcade/` — Interactive 60-FPS 3D Arcade Mini-Game (*Polyglot Core Defender 3D*)

## Features
- Bilingual **EN / VI** instant switch (`localStorage` persisted)
- **Dark** (`#0B1014` KP Obsidian + `#33F6F6` Cyan) & **Light** (`#FAFAFA` + `#0E7490`) theme toggle with WCAG 2.2 AA/AAA contrast
- Zero external JS framework dependencies, mobile-first responsive (`375px` to `1440px+`), SEO + JSON-LD + OpenGraph ready
